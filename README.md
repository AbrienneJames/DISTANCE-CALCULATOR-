# Distance Calculator between 2 Points

## Description
* This Python calculator shows the straight- line distance between 2 points

## How the code works
 1. Call the "math" Library"
 2. Ask the user for variable inputs
 3. Uses distance formule with the sqrt and pow function provided by the library
 4. It shows the result of the calculated distance

## How to run code
* Open your terminal
* Go to Folder that has the code
* Run the code in python

## Input needed
* x1 and x2 (First coordinates)
* y1 and y2 (Second coordinates)

## Sample output
* what is your x1: 3
* what is your x2: 7
* what is your y1: 4
* what is your y2: 9
* The distance between 2 points is: 6.4031242374328485
